# **App Name**: Aether Portfolio OS

## Core Features:

- Desktop Environment: Create a fully functional desktop environment with draggable and resizable windows.
- File System Navigation: Implement a functional file system allowing users to navigate folders, open files, and move back/forward.
- Working Applications: Include usable applications such as a Terminal, TextEdit, and a Browser (with links to external sites) directly within the OS environment.
- Live Desktop Widgets: Incorporate widgets providing live information such as a clock and calendar.
- Interactive Menu Bar & Dock: Design an interactive menu bar and dock for application launching and system controls.
- Portfolio Content Integration: Seamlessly integrate portfolio pieces as native OS elements like documents, images, and projects.
- Dark/Light Mode Toggle: Add ability to change between dark and light mode

## Style Guidelines:

- Primary color: Deep indigo (#4B0082), evoking a sense of professionalism, sophistication, and futuristic tech, suitable for a dark mode OS aesthetic.
- Background color: Near-black (#121212), very desaturated, to emphasize interface elements in dark mode.
- Accent color: Electric violet (#8F00FF), a slightly brighter, attention-grabbing purple, serving to highlight interactive elements and CTAs.
- Font: 'Inter', a sans-serif typeface, for both body text and UI elements to maintain a clean and modern appearance.
- Use minimalist, monochromatic icons in white or light grey to ensure visual consistency and readability within the dark theme. Each app icon should be related to the type of the app.
- Adopt a grid-based layout for the desktop environment and file system, providing structured organization and ease of navigation.
- Incorporate subtle animations for window transitions and UI interactions to enhance the user experience without being distracting.
